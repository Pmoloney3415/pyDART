# pyDART

## Examples

The examples directory is to show small, curated examples, deomnstrating to users how the project works.

- `OMEGA60_illumination.py` runs one fixed forward simulation.
- `six_beam_optimisation.py` runs the configured multi-start six-beam design
  problem. The supplied production deck permits 1000 iterations for each of
  eight starts, so reduce those values when using it as a quick smoke test.
